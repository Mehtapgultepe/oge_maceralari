# Oge Macerası 1v1 · Unity

1. Unity Hub → **New project** → **Universal 3D** şablonu (Unity 6).
2. **Window → Package Manager → + → Install package by name**:
   - `com.unity.netcode.gameobjects`
   - `com.unity.services.multiplayer`
3. **Edit → Project Settings → Services**: Unity hesabınla giriş yap, projeyi bağla (Relay ücretsiz).
4. Bu klasördeki `Assets/Oge` klasörünü projenin `Assets` klasörüne kopyala.
5. Menü: **Oge → 1) Sahneyi kur**, sonra **Play**.
6. Tarayıcı için: Unity Hub'dan **Web Build Support** modülünü ekle → **Oge → 2) WebGL olarak derle**.

Bir hata çıkarsa Console'daki kırmızı satırları kopyala.

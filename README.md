# Oge Macerası

İki kişilik online tarayıcı oyunu: Ayna Dünya, Işık ve Gölge, İple Bağlı, Mıknatıs İkizler, Ateş ve Su. Her oyunda 30 bölüm var.

**Oynamak için:** Sayfayı ikiniz de açın, aynı oda kodunu girin. Biriniz 1. oyuncuyu, öbürünüz 2. oyuncuyu seçsin.

Bağlantı PeerJS ile kuruluyor, sunucu gerekmiyor. Tek dosya: `index.html`.

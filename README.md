# Oge Macerası

İki kişilik online tarayıcı oyunu: Ayna Dünya, Işık ve Gölge, İple Bağlı, Mıknatıs İkizler, Ateş ve Su (30'ar bölüm) ve 3D 1v1 Kapışma.

**Oynamak için:** Sayfayı ikiniz de açın, aynı oda kodunu girin. Biriniz 1. oyuncuyu, öbürünüz 2. oyuncuyu seçsin.

Bağlantı PeerJS ile kuruluyor, sunucu gerekmiyor. Dosyalar: `index.html` ve 3D için `three.min.js` (Three.js r128, MIT).
